# 指标口径与全局红线

**指标口径的唯一真源（CN-3）。** 本文件只定义「怎么算」；具体门槛、基线与波动范围写在验收方案中（CN-57）。产品不含模型能力时，本文件可只保留红线。启用领域包时，可从领域包的 `metrics-seed.md` 选取条目登记。

## 3. 测量约定

| # | 约定 |
|---|---|
| MC-1 | 任何指标结论须注明评测集 ID 与版本、验收方案 ID 与版本。 |
| MC-2 | 基线须在同一配置下至少重复运行两次，记录波动范围；门槛与基线的差距小于波动范围时，不得据此判定达标。 |
| MC-3 | 链路内由模型完成的自查评分不作为验收判据。 |
