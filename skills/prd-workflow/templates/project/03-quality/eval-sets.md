# 评测集登记

**评测集的唯一登记处（CN-3）。** 评测集 ID 形如 `EVAL-001`。评测集内容可存放在库外，本表记录其位置与版本。

| 评测集 ID | 名称 | 版本 | 样本量 | 覆盖范围 | 负责人 | 存放位置 | 状态 |
|---|---|---|---|---|---|---|---|

## 登记要求

| # | 要求 |
|---|---|
| ES-1 | 写明样本量与覆盖范围（问题类型、边界题、反例题）。 |
| ES-2 | 评测集变更后提升版本号；门槛结论只在同一版本内可比。 |
| ES-3 | 含真实用户输入的评测集须脱敏后登记。 |
| ES-4 | 期望结果须以稳定编号标注（如文档编号），不以标题等易变字段标注。 |
