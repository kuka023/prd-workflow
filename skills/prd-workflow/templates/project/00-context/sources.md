# 项目素材登记

项目适配条目的来源编号 `PS-n` 在本文件分配（CN-9），编号永不复用。与单个需求素材包中的 `SRC-n` 相互独立。

原件不入库：放在 `inputs/_project/` 的 raw 子目录（默认不提交）或库外位置，本文件只登记位置并保留经脱敏的关键摘录。

## 1. 素材清单

| # | 类型 | 名称 | 位置 | 日期 | 提供方 | 可信度 | 覆盖内容 |
|---|---|---|---|---|---|---|---|

类型：既有 PRD / 用户旅程 / 系统说明 / 组织与角色清单 / 数据字典 / 会议纪要 / 客户材料 / 原型 / 既有上下文 / 口头确认。
可信度：书面确认 / 会议共识 / 单方陈述。

## 2. 关键摘录

每份素材一节，只摘录项目适配条目所依据的原文。
